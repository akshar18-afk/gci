Add the full event calendar to your phone.

iPhone — Add to Calendar Android — Download & Open to Add to Calendar
If the download doesn't open Calendar automatically:

iPhone: tap the downloaded file in the download banner (or open the Files app → Downloads) — it'll open a screen to add all the events.

Android: follow these steps in the Google Calendar app instead:

  1. Open the Google Calendar app
  2. Tap the menu (☰) → Settings → Add calendar → From URL
  3. Paste this link (or use the copy button below): https://akshar18-afk.github.io/gci/GCI_Fall_2026_Events.ics
  4. Tap Add calendar
